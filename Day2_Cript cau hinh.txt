Trên ASA

! Cấu hình cổng Outside (ISP)
interface Gi0/0
 nameif outside
 security-level 0
 ip address 10.0.0.2 255.255.255.0
 no shutdown

! Sau đó trỏ default route về phía ISP
route outside 0.0.0.0 0.0.0.0 10.0.0.1


! Cấu hình cổng Inside
interface Gi0/1
 nameif inside
 security-level 100
 ip address 192.168.1.1 255.255.255.0
 no shutdown

! Cấu hình cổng DMZ
interface Gi0/2
 nameif dmz
 security-level 50
 ip address 172.16.0.1 255.255.255.0
 no shutdown

! Bật quản trị ASDM
username admin password vnpro
http server enable
http 192.168.1.0 255.255.255.0 inside


Trên ISP:
! Cấu hình Loopback
interface Loopback0
 ip address 8.8.8.8 255.255.255.255
 no shutdown

! Interface nối với ASA
interface gi0/0
 ip address 10.0.0.1 255.255.255.0
 no shutdown



(Neu yeu cau cap DHCP)! Cấu hình DHCP cấp IP cho ASA
ip dhcp excluded-address 10.0.0.1 10.0.0.10   ! Không cấp các IP đầu
ip dhcp pool ISP-POOL
 network 10.0.0.0 255.255.255.0
 default-router 10.0.0.1
 dns-server 8.8.8.8
 lease 1
